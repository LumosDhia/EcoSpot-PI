# EcoSpot - Blog & Events Documentation

## 📦 List of Bundles
- **StofDoctrineExtensionsBundle**
- **KnpPaginatorBundle**
- **DoctrineBundle / DoctrineMigrationsBundle**
- **FrameworkBundle**
- **SecurityBundle**
- **TwigBundle / ExtraBundle**
- **TranslationBundle**

## 🌐 List of APIs
- **Google Translate API**
- **TinyMCE API**: Powering the rich text editor for article creation.

## ✨ List of Custom Functionalities
- **Reaction System**: AJAX-based Like and Dislike logic for articles.
- **View Counter**: Tracking system to count and display article popularity.
- **Reading Time Calculation**: Logic to estimate reading duration based on content length.
- **Language Management**: Session-based switching logic and locale persistence.
- **Dynamic RTL logic**: System that automatically adjusts the layout orientation (LTR/RTL) and direction of UI elements (icons/buttons) based on the current locale.
- **Content Translation Bridge**: Custom service that connects the application to the translation provider with a built-in caching layer.
- **Custom Twig Extensions**: Unique filters for content translation (`|translate`) and HTML entity decoding (`|decode_html_entities`).
- **Interactive Comments**: Form handling and persistence for blog discussions.
- **Enhanced Sorting & Filtering**: Logic for ordering content by publication date and filtering by multiple criteria (categories/tags).
